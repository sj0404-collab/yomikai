# Dictionaries for Yomikai / Словари для Yomikai

Предзагруженные словари в формате Yomitan/Yomichan (`.zip`). Ставятся из
приложения: **Настройки → Словари → Рекомендуемые**.

## Содержимое

| Файл | Что это | Статей | Источник |
|---|---|---|---|
| `JMdict_russian.zip` | Японско-русский | — | [yomidevs/jmdict-yomitan](https://github.com/yomidevs/jmdict-yomitan) |
| `JMdict_english.zip` | Японско-английский с примерами | — | [yomidevs/jmdict-yomitan](https://github.com/yomidevs/jmdict-yomitan) |
| `OpenRussian_en_ru.zip` | Англо-русский / русско-английский | — | [ImenaOphelia/openrussian-to-yomitan](https://github.com/ImenaOphelia/openrussian-to-yomitan) |
| `Russian_Explanatory.zip` | Толковый словарь русского языка | **7 753** | Русский Викисловарь через [kaikki.org](https://kaikki.org) |
| `Latin_to_Cyrillic.zip` | Латиница → кириллица (транслит) | **38 994** | [FrequencyWords](https://github.com/hermitdave/FrequencyWords) (OpenSubtitles) |

### Толковый словарь русского языка

Толкования на русском для наиболее употребительных слов, с пометой части речи
(`сущ.`, `гл.`, `прил.` …) и нумерацией значений, если их несколько.

> **мир** — *сущ.* 1. состояние спокойствия, покоя, согласия; отсутствие вражды, войны …

Лицензия исходных данных: CC BY-SA 3.0 (Русский Викисловарь).

### Латиница → Кириллица

Обратная транслитерация: по латинскому написанию находит русское слово.
Учитывает две распространённые схемы записи — `yo/zh/h/sch` и `e/zh/kh/shch`,
поэтому `privet`, `spasibo`, `devushka`, `ochen` находятся одинаково хорошо.

Полезно, когда OCR распознал русский текст латиницей или когда текст изначально
записан транслитом.

## Как пересобрать

Скрипт `scripts/build_extra_dicts.py` формирует манифест для этих двух
словарей. Сами архивы собираются из открытых источников, указанных в таблице.
