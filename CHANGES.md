# Изменения по тегам

Файл ведётся с v1.9.71. Каждая запись — один тег: что добавлено, что исправлено,
что известно сломанным. Без повторов: изменение упоминается только в теге, где оно вышло.

## [v1.9.72] — 2026-09-12

### Добавлено
- Плавающая кнопка вместо панели оверлея: старт — пузырёк 💬, тап разворачивает
  те же кнопки, что в читалке (▶ Голос, ♀ ♂ 🎙, Выбрать, 🎙 STT, 📋, Копировать,
  ＋ Словарь, Закрыть). `ui/overlay/OcrOverlayService.kt`.
- Режимы области поверх приложений: авто (весь экран) / вручную / фикс
  (реплики игр): полноэкранный селектор пальцем, тонкая рамка фикс-области
  (клики сквозь), режим и рамка хранятся в префах.
- STT для игр в реальном времени: `ui/overlay/GameSttManager.kt` —
  системный SpeechRecognizer с частичными результатами (сразу в бабл),
  финал → перевод → русские голоса тем же движком, что в читалке;
  непрерывный цикл, язык речи/перевод/пол голоса — в настройках.
  Нужно разрешение RECORD_AUDIO (добавлено в манифест, запрос из настроек).
- Отдельные экраны настроек, у каждого свои слайдеры и цифры (дубли убраны):
  `ui/locallibrary/LocalOcrScreens.kt` — точная настройка (8 слайдеров
  порогов/лимитов со сбросом в пресет), область и порядок, голоса и озвучка
  (движок TTS + скорость/высота), озвучка книг (свои скорость/высота),
  игры и STT, оверлей приложений.
- Своя технология распознавания на домен: префы `gameOcrEngine` (по умолчанию
  FAST — скорость для реал-тайма), `bookOcrEngine`, `appOcrEngine` +
  `engineForDomain()`; выбор — радиосписком на экране каждого домена.
- Читалка книг читает скорость/высоту из префов книг и пишет изменения
  слайдеров обратно (настройки переживают перезапуск).

### Исправлено
- EPUB «нет текста»: процент-кодированные href в OPF (русские имена файлов)
  теперь декодируются; служебные записи (NCX, навигация EPUB3, картинки/аудио)
  пропускаются явно; один битый файл больше не убивает всю книгу; фолбэк на
  файлы манифеста при пустом spine; понятная ошибка при отсутствии OPF.
- Пункты настроек, открывавшие один и тот же экран (регион, история,
  «сканер»), заменены уникальными экранами.

### Известно сломанное / не проверено на устройстве
- Живой захват пикселей чужих приложений не входит в этот тег (нужен
  MediaProjection + ImageReader — следующий шаг): авто-режим области = весь
  экран, доменные движки подхватят пути захвата игр/приложений позже;
  манга-конвейер читалки сознательно не тронут.
- STT зависит от системного SpeechRecognizer (обычно Google-сервисы + сеть);
  без них — сообщение об ошибке, не молчание.
- Селектор области и рамка, фокус EditText в оверлее, непрерывный STT-цикл —
  требуют проверки на реальном устройстве.

## [v1.9.71] — 2026-09-12

### Добавлено
- Раздел «Настройки» в локальной библиотеке (третий чип «Манга / Книги / Настройки»,
  выбор запоминается в `local_library_settings_section`):
  `ui/locallibrary/LocalSettingsScreen.kt`.
  Внутри — настройки OCR-баблов (`OcrBubbleSettingsDialog`), полные настройки OCR
  (`SettingsOcrScreen`), плагины распознавания, настройки голосов/TTS
  (`SettingsVoicePluginsScreen`), настройки словарей (`SettingsDictionaryScreen`),
  запуск/остановка OCR-оверлея.
- API-роуты `AiHttpServer` (порт 8765, тот же ключ `?key=`):
  `GET /ocr/settings` — текущие настройки OCR/TTS;
  `POST /ocr/settings` — переключение настроек извне;
  `GET /books/list` — список книг с прогрессом;
  `POST /books/import` — скачать книгу по URL (лимит 40 МБ) в каталог книг.
- Системный OCR-оверлей для других приложений: `ui/overlay/OcrOverlayService`
  (+ регистрация в `AndroidManifest.xml`, разрешение `SYSTEM_ALERT_WINDOW` уже есть).
  Плавающий «бабл» поверх любого APK: текст из буфера обмена (кнопка 📋) или ручной
  ввод, озвучка тем же движком `AutoReadEngine`, что в ридере; перетаскивание,
  сворачивание в пузырёк. Ридеровские баблы не тронуты — оверлей живёт отдельно.
- `BooksStore.importBytes()` — импорт книги из массива байт (используется `/books/import`).

### Исправлено
- Баг «книги не добавляются после выбора файла»: `BooksStore.importBook` больше не
  молчит — возвращает `ImportResult.Success/Failure` с понятной причиной, экран
  показывает Snackbar «Добавлена книга …» / «Не удалось добавить: …» и индикатор
  «Добавление книги…» на время копирования.
- Проверка занятости имени исправлена на `findFile(...)?.exists() == true`
  (защита от вечного цикла при разных реализациях UniFile).
- Если основной каталог книг недоступен, импорт идёт в приватный
  `filesDir/books` — книга добавляется всегда, а не пропадает тихо.

### Известно сломанное / не проверено на устройстве
- `OcrOverlayService` собран по образцу `MiniOverlayService`, но на реальном
  устройстве не гонялся: фокус `EditText`/клавиатура в оверлее и поведение
  `AutoReadEngine` в жизненном цикле сервиса требуют проверки.
- `POST /books/import` качает произвольные URL до 40 МБ в память — больших файлов
  лучше избегать.
- Экраны настроек внутри вкладки «Локальная» зависят от проброшенного
  `LocalBackPress`; системная кнопка «назад» на корне раздела возвращает к «Манге».
