# Отчёт качества — Yomihon v1.9.93: быстрее локальный и онлайн OCR, ML Kit перестаёт выдавать «крякозябры»

## Назначение

Этот отчёт сопровождает единственную разрешённую подписанную release-сборку
`v1.9.93`. Релиз закрывает три жалобы пользователя:

1. локальный Cyrillic OCR в авточтении слишком медленный — на полном кадре
   детектор прогонялся 5 раз (основной + тайлы 2×2), а каждый кроп — через
   PP-OCRv3, контрастный ретрай и верификатор PP-OCRv5 ещё и по каждому слову;
   кадр упирался в таймаут 25 с, поэтому «кириллица работала только вручную»;
2. Google ML Kit на русском тексте отдаёт «крякозябры» — латинские омоглифы и
   мусорную раскодировку с диакритикой (`Êðèñòî`), которые читаются вслух;
3. онлайн-OCR занимает 5–10 с на кадр — картинка улетала размером до 2048 px
   с качеством JPEG до 88.

## Положительные качества

Локальный скан ускоряется квадратично `не меняя констант качества на
правильных входных данных`: тайлы и v5 — это страховочные «вторые мнения» для
пограничных кейсов, а не обязательные проходы каждого кадра. На плотной странице,
где основной детектор видит реплики, тайлы не давали ничего нового; на
длинно-чистой строке v5 лишь подтверждал уже уверенную v3.

Гейт верификатора не снимает защиту от «уверенного мусора»: v3 может дать 0.9 на
латинской крякозябре, но такая строка не проходит `isAcceptableCyrillicOcrText`
после правки омоглифов, и `maySkipVerifier` возвращает false — v5 всё ещё
сравнивается и забирает себе победу через `candidateQuality`.

ML Kit стал безопасен для автоматического фолбэка: раньше его латинский вывод
на русском тексте был просто набором латинских букв, который TTS читал по
символам; теперь такая строка не переживает валидацию. Чистые латинские надписи
(звуки, `SOS`, английские фразы) при этом сохраняются.

Онлайн-ускорение без потери качества распознавания: 1080 px — это всё ещё
огромное разрешение по меркам vision-моделей, которые ужимают вход сами, а
качество JPEG 78 интуитивно для крупного высококонтрастного шрифта баллонов.

## Отрицательные качества и ограничения

Уменьшение картинок онлайн-движков теоретически может потерять очень мелкие
подписи на сверхплотных страницах (лендшафтные омнибусы, тини-лефсайды): порог
1080 px короче прежних 1500–2048 px. Для типичных манги/манхвы и вебтуна текста
это не сказывается; на случай таких страниц остаются локальные движки.

Порог `tilingMinTextBoxes` отключает тайлы на кадрах, где основной проход уже
видит текст: микроскопические облачка размером в десятки пикселей, находившиеся
только тайлами, могут пропускаться. Пороги выбраны с запасом (6–12 боксов), но
полной эмуляции прежних пяти проходов на каждом кадре больше нет — это и есть
источник ускорения.

Онлайн-OCR по-прежнему сетевой вызов плюс инференс на стороне сервера: при
слабой сети или перегруженной модели возможны секунды вплоть до таймаута кадра
(25 с). «Пары миллисекунд» физически недостижимы для любого внешнего API — их
дают только локальные движки; честная цель релиза — вдвое-втрое короче онлайн-ответ.

Первое распознавание локального движка включает загрузку моделей LiteRT
(warm-up) и всё ещё может выйти за 25 с — это бывает один раз за сессию.

## One build — one APK

Сборка выполняется только workflow `Release` по тегу `v*`; `Tests`
(`build.yml`) APK не собирает. Этот кандидат проходит по тому же правилу:
коммит на `main` → тег `v1.9.93` → один подписанный APK + этот отчёт.

## Ручная проверка на устройстве после получения APK

1. Авточтение с локальным движком (Cyrillic PP-OCR) на русской манге/манхве:
   кадр обрабатывается быстрее, страницы листаются без «часиков», результат тот
   же, что раньше получался только ручным сканом по баблу.
2. Авточтение с крайним фолбэком ML Kit (например, отключить пакет моделей
   онлайн): на русском тексте не должно быть латинских омоглифов и `Êðèñòî`;
   чистые надписи латиницей по-прежнему читаются.
3. Онлайн-движки (Glens/ZenFree/Google/OpenRouter): кадр отвечает заметно
   быстрее, реплики не выпадают.
4. «Сканировать и читать» и добор онлайн-текста локальным движком работают без
   прострелов: кириллические строки по-прежнему проходят валидацию.
