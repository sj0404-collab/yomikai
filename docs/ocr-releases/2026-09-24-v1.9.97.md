# Отчёт качества — Yomihon v1.9.97: видео через GitHub-ранер

## Назначение

Закрывает последний незакрытый пункт генерации в AI-чате — видео. По выбору пользователя генерация идёт через GitHub-ранер с PAT-токеном (Python + ffmpeg на ubuntu), а не «Python в браузере»: такой среды в приложении нет. Плюс кнопка «Видео» в быстром ряду генерации.

## Состав изменений

| Область | Что изменено | Ожидаемый эффект |
|---|---|---|
| Workflow | Новый `.github/workflows/video-runner.yml`: dispatch с session/mode/text/images(JSON)/fps, рисует кадры Python-скриптом, кодирует ffmpeg, публикует артефакт `video-<session>`. | Генерация видео «в облаке» не тратит ресурсы телефона. |
| Ранер-клиент | В `RunnerLlm` добавлены `VideoRequest`/`VideoResult` и `startVideo`: dispatch → опрос статусов (`videoStepText`) → скачивание и распаковка mp4 (`fetchVideoArtifact`). | Тот же цикл, что у LLM-раннера: живые статусы и понятные ошибки шага. |
| Инструмент | `gen_video` в `AiChatTools`: текстовая анимация или слайд-шоу из `images`-URL; результат сохраняется в `workspace/videos/*.mp4` и показывается в чате готовым файлом. | «Собери видео из кадров» и «сделай видео про кота» работают из чата. |
| Безопасность | Ранер не исполняет код из запроса: текст рисуется на кадрах, картинки — по URL. | Запрос не превращается в команды на ранере. |
| UI | В `QuickActionsRow` добавлена кнопка «Видео». | Генерация запускается по кнопке. |

## Проверки

- `:app:compileDebugKotlin` — успешно.
- `:app:testDebugUnitTest --tests "eu.kanade.tachiyomi.data.ai.*"` — успешно: `AiChatToolsTest` ×6 (имя `gen_video` в реестре уникально, защита имён от плагинов, документация ровно один раз, дефолтный голос в документации, упоминание GitHub-ранера в описании `gen_video`, регресс reader-инструментов) плюс остальные ai-тесты.
- `render.py` из workflow прошёл `py_compile` (Py 3.12) после дедентирования YAML-блока.

## One build — one APK

Сборка выполняется только workflow `Release` по тегу `v1.9.97`. Ожидается один подписанный arm64-v8a APK; версия и SHA-256 фиксируются runner-ом в отчёте и release.

## Ручная проверка

1. В настройках вкладки AI задан GitHub PAT.
2. В AI-чате нажать «Видео» и дополнить: «… про кота в космосе» — агент вызовет `gen_video`, статус в чате покажет этапы ранера.
3. Через 2–5 минут под ответом появится `videos/*.mp4`, кнопка «Отправить» отдаёт его в Telegram/сохранение.
4. «Сделай слайд-шоу из этих картинок и собери видео» после `gen_image` — ранер скачает кадры и склеит видео.
5. Без токена — агент честно сообщает, что нужен PAT.
