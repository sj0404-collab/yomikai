# Отчёт качества — Yomikai: второй движок кириллицы (KOMA/ONNX)

## Назначение

Кириллица распознавалась единственным путём: LiteRT-модели PP-OCRv3 с
верификатором PP-OCRv5 и «спасательными» эшелонами (сегментация слов,
полосатая нарезка, повторное чтение кропов). Каждый эшелон — это шанс
испортить уже чистую строку и лишние миллисекунды на реплику.

В этой сборке добавлен **второй backend для `OcrModel.CYRILLIC`**,
портированный из читалки KOMA: ONNX Runtime, детектор PP-OCRv4 и
независимый CTC-распознаватель East Slavic PP-OCRv5 со своим словарём.
Один детектор, один распознаватель, один проход.

## Состав изменений

| Область | Что изменено | Ожидаемый эффект |
|---|---|---|
| Новый движок | `data/.../ocr/KomaOnnxOcrEngine.kt`: плитки 1800/160, детектор ≤960 и кратен 32, компоненты связности вместо эшелонов, кроп → поворот → CTC | Быстрее и предсказуемее на чистых облачках |
| Детектор | `data/.../ocr/KomaDetOcrEngine.kt`: адаптер `DetOcrEngine` к тому же ONNX-детектору | Рамки без второй копии модели в памяти |
| Выбор пути | `OcrPreferences.komaOnnxCyrillic()` (`pref_ocr_use_koma_onnx`), ветки в `engineFor(CYRILLIC)` и `detectionEngine()`, `komaModelsInstalled()`, закрытие в `closeEngines()` | Прежний путь остаётся; откат — один переключатель |
| Настройки | «Настройки → Распознавание → Кириллица»: переключатель «Движок KOMA (ONNX)» | Путь включается без adb и без пересборки |
| Модели | `OcrModelFiles`: `koma_ocr/det.onnx` → `koma_det.onnx`, `rec.onnx` → `koma_rec.onnx`, `dict.txt` → `koma_dict.txt` | Модели снаружи APK, как и остальные локальные |
| Зависимости | `onnxruntime-android:1.22.0` в `data` | ONNX-инференс на CPU, 2 потока |

Пайплайн KOMA-пути (что именно проверять на устройстве):

1. страница выше 2800 px режется на плитки 1800 px с перекрытием 160 px;
   дубли на стыке отбрасываются по тексту и `|Δtop| < 0.015`;
2. детектор: масштаб ≤ 960 и кратен 32, нормализация ImageNet;
3. заливка (BFS) по порогу 0.3, отбраковка компонентов меньше 6 пикселей и со
   средним баллом < 0.5, расширение бокса `max(2, w·h·1.5 / 2(w+h))`;
4. кроп; если выше в 1.8 раза — поворот на 90°;
5. распознаватель: вход `3×48×W`, W = 48·w/h, паддинг нулями до ≥ 320,
   нормализация `(x/255−0.5)/0.5`;
6. жадный CTC: словарь = blank + 517 символов + пробел = 519 классов
   (сверено с выходом модели: `519`);
7. сортировка `(top·80).toInt()`, затем `left`.

## Проверки

- Оффлайн-проверка моделей на хосте (numpy-зеркало того же кода, те же ONNX):
  синтетическая строка «У каждой истории есть продолжение» → распознана
  символ в символ, уверенность 0.98, одна рамка.
- Выход распознавателя `[N, T, 519]` и детектора `[1, 1, H, W]` совпадает с
  тем, что ожидает код (проверено `onnxruntime` на тех же файлах).
- Полная сборка и релиз — workflow `Release` по тегу (arm64-v8a, подписанный
  APK).

## One build — one APK

Сборка выполняется только workflow `Release` по тегу. Подписанный arm64-v8a
APK — в Releases.

## Ручная проверка

1. Положить модели в `Android/data/app.yomihon/files/ocr_models/`:
   `koma_det.onnx`, `koma_rec.onnx`, `koma_dict.txt`.
2. Настройки → Распознавание → Кириллица → включить «Движок KOMA (ONNX)».
3. Открыть главу с кириллицей → «Текст страницы». Ожидаемо: рамки совпадают с
   облачками, текст по строкам, латинских вкраплений нет.
4. Сравнить с выключенным переключателем на тех же трёх страницах: время в
   журнале OCR (`AiConsole.ocr` пишет миллисекунды) и число ошибок.
5. Негативные кейсы: пустой баллон `?!` — пустой результат, а не выдуманное
   слово; корейский звуковой эффект — не «русское слово».
6. Выключить модели (удалить файлы) при включённом переключателе: приложение
   должно остаться работоспособным и деградировать на прежний путь, а не
   падать.

## Известные ограничения

- Пробелы между словами CTC не выдаёт — склейка вида `НЕВРЕДИМЫМ` остаётся.
  Лечится прогоном строки через `OcrTextCleaner` и словарь словоформ, это
  следующий шаг, а не часть этой сборки.
- Порядок блоков — эвристика по координатам, не анализ панелей.
- Детектор ищет текст по всей странице, а не только в облачках.
- `onnxruntime-android` добавляет нативные библиотеки: APK стал больше.
