# Отчёт качества — Yomikai v1.9.160: быстрые действия оверлея в шторке

## Назначение

Управление оверлеем было спрятано в саму плавающую панель: чтобы включить или
скрыть кнопку, сменить движок OCR или голос озвучки, нужно было сначала найти
панель на экране. В v1.9.160 те же действия вынесены в постоянное уведомление
(шторку) — они доступны даже когда кнопка скрыта или её не видно.

## Состав изменений

| Область | Что изменено | Ожидаемый эффект |
|---|---|---|
| Уведомление | Из `ensureForeground()` выделен `buildNotification()` с текущими движком и голосом в подписи | Видно, что выбрано, прямо в шторке |
| Действия | `Включить` / `Скрыть` / `Движок` / `Голос` — `PendingIntent` на сам сервис | Управление без входа в панель; сервис не поднимается заново |
| Видимость | Флаг `overlayHiddenByUser`: ручное скрытие не перекрывается авто-логикой `ProcessLifecycleOwner` | «Скрыть» убирает кнопку до нажатия «Включить» |
| Движок | `cycleOverlayEngine()` дополнительно обновляет уведомление | Смена движка и его подпись синхронны |
| Голос | `cycleVoice()`: авто → мужской → женский → средний (`VoicePreset.Gender3`) | Быстрое переключение тембра озвучки из шторки |

## Проверки

- Локальная компиляция `:app:compileDebugKotlin` — `BUILD SUCCESSFUL`.
- Полная сборка и релиз — workflow `Release` по тегу `v1.9.160` (arm64-v8a,
  подписанный APK).

## One build — one APK

Сборка выполняется только workflow `Release` по тегу `v1.9.160`. Подписанный
arm64-v8a APK — в Releases.

## Ручная проверка

1. Запустить оверлей. Опустить шторку — у уведомления «OCR-кнопка» кнопки
   «Включить», «Скрыть», «Движок», «Голос».
2. «Скрыть» — круглая кнопка пропадает и не возвращается сама. «Включить» —
   появляется снова (вне Yomikai).
3. «Движок» — движок переключается по кругу, в подписи уведомления и в тосте
   виден новый.
4. «Голос» — тембр меняется по кругу (авто/мужской/женский/средний),
   следующий бабл читается выбранным голосом.

## Известные ограничения

- В свёрнутой шторке Android показывает три действия, четвёртое — в
  «развернуть». Порядок: Включить / Скрыть / Движок / Голос.
- **Служба доступности у APK не из магазина блокируется системой.** Снять
  блокировку можно только вручную: «О приложении» → ⋮ → «Разрешить
  ограниченные настройки».
- **Картинка кадра в окне не показывается** — только распознанный текст в
  бабле.
