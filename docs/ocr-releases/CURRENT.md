# Отчёт качества — Yomihon v1.9.113: оверлей читает рамку сам

## Назначение

Оверлей поверх чужого приложения больше не ограничен буфером обмена и
микрофоном: он снимает кадр области через MediaProjection, распознаёт его,
озвучивает и листает приложение своим жестом. Заодно исправлены четыре
бага, найденные читателем на устройстве, и панель оверлея переделана под вид
читалки.

## Состав изменений

| Область | Что изменено | Ожидаемый эффект |
|---|---|---|
| Захват | `OverlayCaptureEngine`: VirtualDisplay + ImageReader, вырезание рамки, переживание half-initialized состояния | Кадр области снимается стабильно, а не один раз |
| Разрешение | `OcrCaptureActivity` — прозрачная activity | MediaProjection нельзя начать из сервиса; activity только спрашивает и закрывается |
| Прокрутка | `OverlayGestureService` (AccessibilityService, только `dispatchGesture`), `GestureSwipe`, ожидание результата жеста | Листание проверяется по ответу системы, а не по факту отправки |
| Чтение | `OverlayAutoReader`: кадр → OCR → озвучка → ожидание конца речи → свайп | Реплики идут подряд, приложение листается само |
| Движок | `OcrRepository.recognizeText(image, model)` | Переключатель «свой движок оверлея» действительно меняет движок |
| Android 14+ | `mediaProjection` в типах FGS, `FOREGROUND_SERVICE_MEDIA_PROJECTION` | Без этого `getMediaProjection()` падает в SecurityException |
| Трекеры | `SeriesDto`, `VolumeDto`, `HKPagination` со значениями по умолчанию; `coerceInputValues` | Неполный ответ сервера больше не роняет разбор |
| Источник | Повтор запроса при 5xx/429/таймауте/обрыве, кнопка «Повторить» в snackbar | Вместо «0 глав» — список глав или честная ошибка с повтором |
| Скриншот | Фону передаётся своя копия кадра | Нет падения сразу после «Скриншот сохранён» |
| Вид оверлея | Круглая кнопка в углу, вертикальное меню «подпись + кнопка», привязка к краям | Панель выглядит частью управления, а не отдельным экраном |
| Маркет | Убраны кампания поддержки Mihon, пункт «Поддержите нас», упоминания Mihon в строках | В приложении нет чужой рекламы и текста от чужого разработчика |

## Ручная проверка

1. Включить Службу доступности «Yomikai — прокрутка рамки».
2. В настройках оверлея выделить область кнопкой ✏.
3. В чужом приложении нажать круглую кнопку в углу и выбрать «Читать рамку»,
   разрешить захват экрана.
4. Проверить: реплика озвучивается, после неё приложение листается само, текст
   меняется. Если прокрутки нет — должна появиться подпись «Прокрутка не идёт».
5. Нажать «⏹ Стоп-чтение».
6. Перетащить кнопку в другой угол и отпустить: она должна прижаться к краю.

## Известные ограничения

- **Листание требует Службы доступности.** Без неё прокрутить чужое
  приложение нечем: свой жест отправлять нечем. Служба ничего не читает и
  ничего не выполняет.
- **Картинка кадра в окне не показывается** — только распознанный текст в
  бабле. Показ страницы в рамке остаётся отдельной задачей.
- **Точность распознавания игровых шрифтов не проверена**: движок оверлея
  можно задать отдельно от движка читалки, но на устройстве это ещё никто не
  сравнивал.
