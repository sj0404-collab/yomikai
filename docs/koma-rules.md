# Правила чтения без пересборки APK

## Куда класть файл

```
/data/data/<пакет>/files/koma-plugins/koma-rules.json     ← числа (правила)
/data/data/<пакет>/files/koma-plugins/koma-rules.dex      ← плагин (код)
```

Через приложение: читалка → «Ещё» → **«Правила и буфер строк»** → «Заменить файл».
Через файловый менеджер/ADB: просто положить файл по пути выше.

## Что означает каждое число

| Поле | Что делает | Как подбирать |
|---|---|---|
| `inkLowPercentile` / `inkHighPercentile` | какие 2 % и 98 % яркости считать буквами и фоном | серый текст на белом: 0.02 / 0.98 |
| `inkFlatSpread` | если разброс яркости меньше — участок пустой | поднять, если на пустых полях находится «текст» |
| `inkCoefficient` | 0 — порог ближе к буквам (жирнее), 1 — к фону (ловит бледное) | бледный текст не виден → 0.6–0.7 |
| `inkMin` / `inkMax` | границы порога | не трогать без нужды |
| `binarizeFallback` | порог для однородного участка | старое поведение — 110 |
| `contrastGain` / `contrastOffset` | растяжка уровней для третьего прохода | 2.2 / −140 по умолчанию |
| `rescueMinRegions` | когда включать страховочные проходы | меньше — агрессивнее |
| `pageSide` / `rescueSide` | сторона детектора: основной / страховочный | 1600 / 960 |
| `minConfidence` | порог уверенности распознавания | 0.25 |
| `cutMargin` | запас снизу полосы, при котором реплика считается обрезанной | 0.06 |
| `bandOverlap` / `bandsMax` / `wholeThreshold` | нарезка длинной страницы на полосы | 0.15 / 8 / 0.72 |
| `bubbleGap` | зазор склейки фрагментов в одну реплику (доли высоты строки) | 0.45 |

## Порядок проверки правки

1. Поменять число в `koma-rules.json`.
2. Читалка → «Правила и буфер строк» → **«Перезагрузить»** (видно новую версию).
3. **«Пересчитать из буфера»** — порядок и склейка пересчитываются по уже
   распознанным строкам, без 6–12 секунд OCR.
4. Если поменялся порог «чернил» (сам текст) — «Распознать заново»: это
   перечитывает картинку, тут без OCR не обойтись.

## Плагин (.dex)

Класс `koma.rules.Plugin` с конструктором без аргументов, реализует
`eu.kanade.tachiyomi.ui.koma.KomaRulesPlugin`:

```kotlin
package koma.rules

class Plugin : eu.kanade.tachiyomi.ui.koma.KomaRulesPlugin {
    override fun rulesJson(): String = """{ "version": "my-1", "inkCoefficient": 0.62 }"""
}
```

Собирается как обычный dex (`d8`) против `app-debug.apk` как classpath. Файл
кидается в `files/koma-plugins/koma-rules.dex`, приложение подхватывает его при
следующем перечитывании правил. Плагин главнее JSON-файла.
