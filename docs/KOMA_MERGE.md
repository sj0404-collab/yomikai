# KOMA внутри Yomikai: один APK вместо двух приложений

Раньше существовали две отдельные сборки: Yomikai (читалка манги/книг + OCR)
и KOMA (`com.agon.app` — библиотека CBZ/CBR/PDF с локальным OCR). Начиная с
**v2.1.0** KOMA — это раздел внутри Yomikai: один `applicationId app.yomikai`,
одна иконка в лончере, один APK.

## Где найти

`Библиотека → (вкладка) Локальная библиотека → чип «KOMA»`

Чипы раздела повторяют прежние экраны KOMA:

| Чип | Что делает |
| --- | --- |
| Библиотека | Полка книг, категории, избранное, баннер «Продолжить», импорт CBZ/CBR/PDF |
| Каталог | Поиск по Internet Archive (1800–1930), загрузка CBZ/PDF, книга по прямой HTTPS-ссылке |
| AI-студия | OCR-языки, автораспознавание, подключение TTF/OTF для стиля текста |
| Настройки | Тема (Бумага/Ночь/Система), «не гасить экран», кэш OCR, статистика, About |

Читалка открывается на весь экран: `HorizontalPager` (справа налево для манги),
вертикальная лента для манхвы/маньхуа, зум 1–5× без масштабирования исходника,
оверлей bounding-боксов, панель OCR, экспорт распознанных страниц в `.txt`.

## Что перенесено как есть

- `app/src/main/java/eu/kanade/tachiyomi/ui/koma/` — весь код KOMA
  (пакет `com.agon.app.*` → `eu.kanade.tachiyomi.ui.koma`, единый пакет без
  подпакетов: `KomaLibrary.kt`, `KomaOcrEngine.kt`, `KomaHomeScreen.kt`,
  `KomaExtraScreens.kt`, `KomaReaderScreen.kt`, `KomaTheme.kt`).
- Ресурсы с префиксом, чтобы не пересекаться с ресурсами Yomikai:
  `res/font/koma_manrope*.ttf`, `res/drawable/koma_reading_banner.png`.
- Ассеты в собственном корне `assets/koma/`: `models/` (PP-OCR det + cyrillic rec
  + словарь), `books/` (демо-сканы: Хокусай II и VI, Blue Beetle № 15 — по 10
  страниц на книгу), `licenses/`.
- Данные KOMA изолированы: `SharedPreferences("koma")` + `filesDir/library/`,
  кэш OCR — `filesDir/ocr/`. Существующие установки KOMA данные не теряют
  только при переустановке с тем же пакетом; здесь пакет новый (`app.yomikai`),
  поэтому полка начинается с демо-книг.

## Что изменено при слиянии

- **Навигация**: нижняя панель KOMA заменена на строку чипов внутри раздела —
  иначе получались две нижние панели (своя + Yomikai).
- **Тема**: `AgonAppTheme` → `KomaTheme`, по умолчанию следует теме приложения,
  переключатель «Бумага / Ночь / Система» остался в настройках раздела.
- **OCR**: оставлены три движка, которые реально есть в сборке:
  ML Kit (японский, латиница) и PaddleOCR/ONNX (кириллица, модели в APK).
  Ветки китайского и корейского ML Kit убраны — их моделей в APK нет, а
  показывать языки, которые не работают, хуже, чем не показывать их.
- **Границы экрана**: убран ручной разбор системных вставок
  (`isAppearanceLightStatusBars`) — этим управляет активность Yomikai;
  читалка KOMA рисует собственный фон и прячет чипы раздела.
- **Зависимости** (каталог `gradle/libs.versions.toml`, модуль `:app`):
  `com.github.junrar:junrar` (CBR), `com.google.mlkit:text-recognition` и
  `…-japanese`, `com.microsoft.onnxruntime:onnxruntime-android`
  (в `:data` они были `implementation`, то есть не видны `:app`).

## Сборка и проверка

Локальный Gradle тут не используется: сборка идёт тем же GitHub-воркфлоу,
что и остальные релизы (`Release`), проверка компиляции — `Tests`.
Порядок: ветка → PR → зелёный `Tests` → тег `v2.1.0` (versionCode `21000`) →
`Release` → зеркало APK на gofile.

## Ограничения

- CBR поддерживается только RAR4 (как и в KOMA): RAR5 и архивы с паролем
  отклоняются с понятным сообщением.
- PDF рендерится в JPEG 1400 px по ширине (как в KOMA).
- Каталог Internet Archive ограничен изданиями 1800–1930 годов — это прежняя
  логика KOMA, не регресс.
